# دليل ملفات المشروع — أين تعدّل؟

> القاعدة الذهبية: **المنطق في `app.py` + `database.py`**، و**الشكل في `templates/`**.
> بعد أي تعديل على ملف `.py` أعد تشغيل السيرفر (`Ctrl+C` ثم `python run.py`).
> القوالب `.html` تتحدث مباشرة بدون إعادة تشغيل.

## 1. الملفات الأساسية (الجذر)

| الملف | عمله | متى تفتحه؟ |
|---|---|---|
| `app.py` | التطبيق كله: كل الصفحات والمسارات (Routes) والصلاحيات | إضافة/تعديل أي صفحة أو رابط أو صلاحية |
| `database.py` | كل عمليات قاعدة البيانات: الفواتير، السداد، القيود، التقارير المالية، السنوات، الجرد | إضافة/تعديل أي حسابات أو معادلة مالية |
| `models.py` | تعريف جداول قاعدة البيانات (SQLAlchemy) | إضافة جدول أو عمود جديد |
| `financial_fixes.py` | التحصيل اليدوي + إصلاحات الفواتير (شهر واحد/إعادة الترحيل/الحذف بعكس) | مشاكل التحصيل اليدوي أو الفواتير المكررة |
| `payments.py` | مسارات السداد (Blueprint احتياطي يُستخدم عند غياب المسار الأساسي) | مشاكل صفحة السداد |
| `jobs.py` | المهام الخلفية مع تتبع التقدم (توليد الفواتير + تصدير PDF) | إضافة عملية طويلة جديدة بنافذة تقدم |
| `run.py` | تشغيل السيرفر (المنفذ الافتراضي 5006) | تغيير المنفذ أو إعدادات التشغيل |
| `requirements.txt` | مكتبات بايثون المطلوبة | تثبيت بيئة جديدة |
| `create_user.py` | سكربت إنشاء مستخدم من سطر الأوامر | إضافة مدير/موظف يدويًا |
| `init_schema.py` | تهيئة قاعدة البيانات لمرة واحدة | قاعدة جديدة فارغة |
| `reset_financials.py` | تصفير البيانات المالية (ينسخ احتياطيًا أولًا!) | ⚠️ خطر — لا تشغله إلا عند الحاجة القصوى |
| `import_custom.py` | سكربت استيراد لمرة واحدة من ملف Excel قديم | انتهت مهمته — لا تلمسه |

## 3. المجلدات

| المجلد | عمله | ملاحظة |
|---|---|---|
| `static/css` `static/js` | التنسيقات والسكربتات | تعديل الشكل العام |
| `static/icons` + `manifest.json` + `service-worker.js` | تطبيق الهاتف (PWA) | لا تلمس إلا لسبب |
| `instance/` | قاعدة البيانات `water_billing.sqlite3` + مفتاح الجلسة | ⚠️ انسخها احتياطيًا قبل أي تجربة |
| `uploads/` | مرفقات الفواتير والسداد | لا تحذف — مرتبطة بسجلات |
| `docs/` | التوثيق (هذا الملف + التوثيق الفني) | |

## 4. خريطة سريعة: أريد أن...

- أضيف حقلًا للمشترك ← `models.py` (الجدول) + `database.py` (الحفظ) + `subscriber_form.html` (الواجهة)
- أغيّر شكل الفاتورة المطبوعة ← `invoice_print.html`
- أضيف تقريرًا ماليًا ← دالة في `database.py` + مسار في `app.py` + قالب جديد + رابط في `base.html`
- أغيّر صلاحية صفحة ← سطر `@role_required` فوق المسار في `app.py`
- أضيف حسابًا محاسبيًا ← من صفحة شجرة الحسابات (بدون كود)، أو `ensure_accounting_seed` في `database.py` للحسابات الافتراضية
